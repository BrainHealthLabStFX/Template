# Using This Repository Template

## Starting a New Repository

GitHub has provided a guide on how to create a new repository from this repository template [here](https://docs.github.com/en/repositories/creating-and-managing-repositories/creating-a-repository-from-a-template#creating-a-repository-from-a-template).

If you are creating this repository for the Brain Health Lab page, choose BrainHealthLabStFX as the Owner in step 4 of the above linked guide.

When naming the new repository, please use [Pascal Case](https://stringcase.org/cases/pascal/).

## Transfer an Existing Repository

If you have already created a GitHub repository on your personal account, you can transfer it to Brain Health Lab using the instructions [here](https://docs.github.com/en/repositories/creating-and-managing-repositories/transferring-a-repository). Make sure the repository is named using [Pascal Case](https://stringcase.org/cases/pascal/) before transferring.
